# Level 3 Study Studio — revised 1 November 2026

English study materials for eight non-programming Level 3 subjects: 82 lessons, 16 practice tests, 82 MCQs and 82 written questions, with worked explanations and self-checks.

## Study route
Read the concept and conditions. Follow the worked steps, then cover the answer and try the self-check. Attempt practice without notes. Review mistakes and retry later.

## PDF and LaTeX
All ten final PDF documents are compiled from LaTeX. The complete book includes all eight subject handouts. The practice book collects the sixteen tests and explained answers. Editable sources and figure PDFs are in latex-sources.zip. Compile main.tex or a subject entry point with Tectonic or XeLaTeX; keep preamble.tex, subject bodies and figures together.

## Website
Open index.html in the website folder, or use the published GitHub Pages website. No student sign-in is needed. Math uses local KaTeX assets. Progress stays in the current browser; export/import a backup to move devices. Lesson completion is self-reported; MCQ scores use the most recent submitted answers. Written practice is self-marked.

## Scope
Based on the accessible supplied Level 3 course files. The source audit inventories 159 non-programming files; 95 provided substantial extracted text. Scanned and handwritten material was not fully transcribed. These original practice questions are study aids, not predictions of an examination. Check lecturer-specific scope and conventions.
